# Напоминалка

Android-приложение: ставишь напоминание (текст + дата + время) — в нужный момент прилетает уведомление с вибрацией. Работает в Doze (точные будильники), переживает перезагрузку телефона.

Стек: Kotlin, Jetpack Compose (Material 3), AlarmManager, без сторонних библиотек. minSdk 26 (Android 8+).

## Как собрать

### Вариант 1 — Android Studio
1. Открыть папку проекта в Android Studio (File → Open).
2. Дождаться синхронизации Gradle (если спросит про wrapper — согласиться создать).
3. Run ▶ на подключённом телефоне (включить отладку по USB) или Build → Build APK.

### Вариант 2 — без компа, через GitHub
1. Создать репозиторий на GitHub, залить туда эту папку.
2. Вкладка Actions → workflow «Build APK» соберётся сам при пуше (или запустить вручную «Run workflow»).
3. Внизу страницы запуска — артефакт `napominalka-debug-apk`, внутри `app-debug.apk`.
4. Скачать на телефон, разрешить установку из неизвестных источников, установить.

## Структура
```
app/src/main/java/com/example/napominalka/
  MainActivity.kt        — UI (список + диалог добавления)
  Reminder.kt            — модель + хранение (SharedPreferences, JSON)
  ReminderScheduler.kt   — постановка/отмена будильников
  ReminderReceiver.kt    — показ уведомления + BootReceiver
```

## Идеи для развития
- повторяющиеся напоминания (каждый день / неделю)
- кнопка «отложить на 10 мин» прямо в уведомлении
- отдельный звук, свой значок
- виджет на рабочий стол
